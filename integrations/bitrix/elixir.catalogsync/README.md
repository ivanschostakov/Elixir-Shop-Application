# Elixir Catalog Sync

Модуль делает Bitrix источником контента карточек приложения:

- `ELIXIR_APP_DESCRIPTION` → `products.description`;
- `ELIXIR_APP_USAGE` → `products.usage`;
- `ELIXIR_APP_STORAGE` → `products.expiration` (в приложении это вкладка «Хранение»).

Сначала используется точное совпадение `XML_ID` Bitrix и `system_id`
приложения. Для товаров, которые МойСклад пересоздал с новым UUID,
разрешён резервный поиск только по уникальному артикулу `CML2_ARTICLE`.
Дубли артикулов автоматически отклоняются; сопоставления по названию нет.
Название, цена, остаток, активность и варианты модулем не изменяются.

Подтверждённый UUID приложения сохраняется в служебном свойстве
`ELIXIR_APP_SYSTEM_ID`. Это делает последующие циклы независимыми от старого
`XML_ID` Bitrix и не влияет на публичную карточку товара.

Три свойства являются отдельными app-only HTML-полями. Стандартные
`PREVIEW_TEXT`, `DETAIL_TEXT`, публичный шаблон и поведение сайта не меняются.

Endpoint:

```text
/bitrix/tools/elixir.catalogsync/sync.php
```

Он принимает только подписанный `POST {"action":"pull"}` с production-IP
приложения. Используются HMAC-SHA256, timestamp ±5 минут, IP allowlist,
файловый rate limit вне `public_html` и отдельный secret.

Пустое поле Bitrix очищает соответствующее поле приложения. Поэтому перед
первым включением worker выполняется одноразовый seed текущего контента
приложения в новые свойства Bitrix и сверяются количества заполненных полей.

## Где редактировать

1. В административной панели Bitrix открыть «Контент» → «Каталог товаров» →
   «Товары».
2. Открыть нужный товар и найти свойства:
   «Описание для приложения», «Применение для приложения» и
   «Хранение для приложения».
3. Сохранить товар. Изменение появится в приложении не позднее чем через
   пять минут.

После запуска модуля эти три поля редактируются только в Bitrix. Изменение
одноимённых полей в админке приложения будет заменено значением Bitrix на
следующем цикле. Удаление текста из свойства Bitrix также очистит
соответствующую вкладку в приложении.

Удаление модуля не удаляет свойства или записанный в них контент.
