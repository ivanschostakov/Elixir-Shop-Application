Значения секретов сюда не записывать. Документ используется как checklist.

## Целевой Bitrix

- [x] подтверждён production-домен;
- [x] подтверждён IP/hostname сервера;
- [x] подтверждён способ SSH/SFTP-доступа;
- [x] известен фактический `DOCUMENT_ROOT`;
- [x] известны владелец/группа файлов и пользователь PHP-FPM;

- [x] подтверждён рабочий HTTPS `8443` из allowlist;
