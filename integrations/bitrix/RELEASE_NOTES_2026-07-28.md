# Elixir Bitrix release — 2026-07-28

## Подготовлено

- новый модуль `elixir.promo` 1.2.0;
- защищённые операции `lookup` и `quote`;
- расчёт скидки штатной корзиной Bitrix;
- автоматическое создание купона при новом/изменённом `UF_PROMO`;
- приложение использует тот же пользовательский контекст скидок, что и
  оформление заказа на сайте;
- собственный промокод больше не даёт скидку владельцу, внешний/`ELIXIR`
  начинает с 3%, сохранённый реферерский код применяет группу 3–20%;
- прогресс оплаченных покупок приложения учитывается в Bitrix идемпотентно для
  общей суммы покупок и единой персональной скидки;
- Bitrix рассчитывает прямые и двухуровневые начисления без их записи;
- журнал начислений приложения и статусы закрытия месяца хранятся отдельно в
  PostgreSQL приложения и доступны в админке в разделе рефералов;
- worker приложения повторяет неудавшуюся фиксацию прогресса покупки через
  Bitrix API, не влияя на уже завершённую оплату;
- фирменный `ELIXIR` и обычный скидочный купон не создают реферальное
  начисление старому закреплённому рефереру;
- собственный промокод выдаётся модулем при достижении 100 000 ₽ без зависимости
  от неработающей legacy-функции в `init.php`;
- отсутствует публичная массовая синхронизация;
- исправлена явная автозагрузка `elixir.reviewsync`;
- добавлена форма настройки secret для `elixir.reviewsync`;
- app integration защищён отдельным token, IP allowlist и rate limit;
- giveaway endpoint сохраняет контракт действующего бота и защищён token/IP/rate limit;
- API-ошибки дополнены русским и английским сообщениями;
- backend применяет расчёт Bitrix к реальной корзине заказа;
- товары сопоставляются по ID, XML_ID варианта, артикулу и XML_ID родителя;
- покупатель Bitrix сопоставляется по email, а при отсутствии считается анонимным;
- добавлен клиент входа через профиль сайта без связи с администраторами;
- устранена обратная отправка только что импортированных отзывов;
- старые отзывы читают актуальный UUID МойСклад из связанной карточки Bitrix;
- поддержано строгое разрешение UUID варианта в родительский товар;
- исправлена запись пустого ответа в обязательное поле Sotbit;
- install-script сохраняет владельца и группу закрытых config-файлов;
- внутренние клиенты используют allowlisted HTTPS `8443`, не меняя публичный сайт;
- каталог включает готовые косметические товары и исключает папку сырья;
- добавлен статус интеграции «Промокоды Bitrix» в админке;
- production secrets исключены из исходников.
