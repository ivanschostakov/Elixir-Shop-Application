# Внутренние ссылки приложения Elixir Shop

Этот справочник используется во всех местах админки, где можно задать переход внутри приложения:

- `Контент → Баннеры → Внутренняя ссылка`;
- `Маркетинг → Кампании → Внутренняя ссылка`;
- `Маркетинг → Автоматизации → Внутренняя ссылка`;
- `Автоматизация → Правила заказов → Отправить push → Внутренняя ссылка`.

В каждом из этих полей есть кнопка «Открыть полный справочник страниц и параметров». Кнопка «Использовать» подставляет готовый пример в поле.

## Общие правила

1. Внутренняя ссылка начинается с одного символа `/`.
2. Домен приложения указывать не нужно.
3. Для баннера заполняется только одно поле: внутренняя или внешняя ссылка.
4. Внешняя ссылка баннера должна быть полным `https://` или `http://` URL.
5. Несколько параметров соединяются символом `&`.
6. Значения параметров с пробелами и специальными символами нужно URL-кодировать.
7. ID товара, категории, заказа, черновика, темы и обращения должны быть положительными числами.
8. Если экран требует авторизацию, неавторизованный пользователь сначала должен войти в аккаунт.

## Полная карта экранов

| Экран | Путь | Параметры и дополнения | Пример | Доступ |
|---|---|---|---|---|
| Главная | `/` | Нет | `/` | Для всех |
| Каталог товаров | `/discover` | `tab=products` | `/discover?tab=products` | Для всех |
| Статьи | `/discover` | `tab=articles` | `/discover?tab=articles` | Для всех |
| Поиск по каталогу | `/discover` | `q=запрос`, рекомендуется `tab=products` | `/discover?tab=products&q=ghk-cu` | Для всех |
| Категория товаров | `/discover` | `categoryId=ID`, `resetCategory=1` сбрасывает фильтр | `/discover?tab=products&categoryId=12` | Для всех |
| Карточка товара | `/products/{productId}` | `productId` — числовой ID товара | `/products/123` | Для всех |
| Корзина | `/basket` | Нет | `/basket` | Для всех |
| Избранное | `/favorites` | `tab=products` или `tab=articles` | `/favorites?tab=products` | Нужен вход |
| AI-чат | `/chat` | `mode=ai` | `/chat?mode=ai` | Нужен вход |
| Чат сообщества | `/chat` | `mode=community`, необязательно `topicId=ID темы` | `/chat?mode=community` | Нужен вход |
| Поддержка | `/chat` | `mode=support`, необязательно `conversationId=ID обращения` | `/chat?mode=support` | Нужен вход |
| Профиль | `/profile` | Нет | `/profile` | Нужен вход |
| Персональные данные | `/personal-data` | Нет | `/personal-data` | Нужен вход |
| Черновики заказов | `/profile-drafts` | Нет | `/profile-drafts` | Нужен вход |
| История заказов | `/profile-history` | Нет | `/profile-history` | Нужен вход |
| Оформление заказа | `/checkout` | `draftId=ID черновика`, `code=промокод` | `/checkout` | Нужна корзина или черновик |
| Выбор доставки | `/delivery` | `draftId=ID черновика`, `syncBasket=1` | `/delivery` | Нужна корзина или черновик |
| Оплата | `/payment` | `orderId` или `draftId`, `paymentMethod=sbp\|later`, `code=промокод` | `/payment?orderId=123` | Нужен конкретный заказ |
| Контакты | `/contacts` | Нет | `/contacts` | Для всех |
| Реквизиты | `/requisites` | Нет | `/requisites` | Для всех |
| Публичная оферта | `/public-offer` | Нет | `/public-offer` | Для всех |

## Комбинирование параметров

Открыть каталог, выбрать товары, категорию 12 и выполнить поиск:

```text
/discover?tab=products&categoryId=12&q=ghk-cu
```

Открыть определённую тему сообщества:

```text
/chat?mode=community&topicId=25
```

Открыть обращение поддержки:

```text
/chat?mode=support&conversationId=123
```

Открыть оформление сохранённого черновика с промокодом:

```text
/checkout?draftId=456&code=SALE10
```

## Ограничения контекстных ссылок

- Не используйте один `orderId`, `draftId` или `conversationId` в массовой push-кампании: такой объект принадлежит конкретному клиенту.
- `/checkout` без `draftId` использует текущую корзину пользователя.
- `/payment` следует открывать только при наличии конкретного заказа или черновика.
- `topicId` должен существовать в сообществе.
- `conversationId` должен принадлежать получателю ссылки.
- Если нужен обычный массовый переход к заказам, используйте `/profile-history`, а не статический `/payment?orderId=...`.
